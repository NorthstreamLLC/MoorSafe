# MoorSafe website

Static site — no build step. Deploy the contents of this folder to the repo root (GitHub Pages: Settings → Pages → Deploy from branch → main / root).

Pages: index.html · solution.html · about.html · blog.html · info-packet.html
Runtime: support.js (required), doc-page.js (info packet)

## Before launch
- Replace uploads/video_water.mp4 with the new hero footage (same filename).
- Set real prices, checkout URL and contact email: search each .html for data-props and edit the "default" values (price300/400/500, checkoutUrl, contactEmail).
- Add Scott's headshot in about.html (placeholder circle).
